Win32 app says "not installed" but it is? Check STDERR

Mathew Dailey · November 25, 2026

Using a custom PowerShell detection script for a Win32 app? Intune only marks it installed when the script exits 0 and writes something to STDOUT.

The catch

If anything is written to STDERR, the app is reported as not installed, even with exit 0 and STDOUT data. One noisy cmdlet warning can cause endless reinstall loops.

Where to look on the device

Logs are in C:\ProgramData\Microsoft\IntuneManagementExtension\Logs. Open them with CMTrace.

  • AppWorkload.log: check-ins, installs, applicability and detection for Win32 apps.
  • AppActionProcessor.log: detection and applicability decisions.
  • AgentExecutor.log: PowerShell script runs.
  • HealthScripts.log: Remediations and custom compliance scripts.

Quick fixes

  • Add -ErrorAction SilentlyContinue to probes that may fail.
  • Write one Write-Output line only on success.
  • Exit 0 or 1 on purpose.

To force a fresh check-in, use Company Portal → Settings → Sync. It triggers both MDM and IME check-ins.

Remediation detection scripts have their own exit-code rules; see why a Remediation "never finds an issue".
