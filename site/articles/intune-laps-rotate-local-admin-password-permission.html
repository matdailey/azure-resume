"Rotate local admin password" is greyed out, even for Intune Admins

Mathew Dailey · November 25, 2026

Your helpdesk can see the Windows LAPS password but can't rotate it after using it? That's by design, not a bug.

Rotation isn't in any built-in role

The Intune remote task "Rotate Local Admin Password" isn't included in any built-in Intune role, not even the Entra Intune Administrator role. You have to grant it on purpose.

Viewing and rotating are separate permissions

  • View the password: Entra permission microsoft.directory/deviceLocalCredentials/password/read. Cloud Device Administrator has it, or build a custom role.
  • Rotate it: an Intune custom role with Managed devices: Read, Organization: Read, and Remote tasks: Rotate Local Admin Password.

Two tips for tight tenants

  1. Scope password read to an Administrative Unit so a site helpdesk can only recover passwords for its own devices.
  2. Set LAPS post-authentication actions (reset password, sign out) so a used password doesn't stay valid. Manual rotation then becomes the exception, and every rotation lands in the audit log.

If you scope helpdesk roles to Administrative Units, check that your admin MFA policy actually covers AU-scoped roles.
